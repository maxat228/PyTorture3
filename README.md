# Лабораторная работа №3. Очередь задач: итераторы и генераторы

## Описание
Реализация очереди задач (TaskQueue) с кастомным итератором, повторным обходом,
ленивыми фильтрами через генераторы и полной интеграцией с моделью задачи
на дескрипторах и источниками через протокол TaskSource.
Проект связывает все три лабораторные работы в единую архитектуру:
протоколы (ЛР1) → дескрипторы и @property (ЛР2) → итераторы и генераторы (ЛР3).

## Реализация
- **Task** — модель задачи с дескрипторами (id, priority, status) и @property
- **TaskQueue** — коллекция задач с `add_task`, `__len__`, `__getitem__`
- **TaskQueueIterator** — кастомный итератор с `__next__` и `StopIteration`
- **Повторный обход** — новый итератор при каждом `for`
- **filter_by_status** — генератор, ленивая фильтрация по статусу
- **filter_by_priority** — генератор, ленивая фильтрация по приоритету (>=)
- **Протокол TaskSource** — контракт для источников задач
- **Источники** — FileSource (из файла), ApiSource (заглушка), RandomSource (генерация)
- **load_from_source** — загрузка задач из любого источника в очередь
- **from_source** — создание одной задачи из источника
- **Интеграционные тесты** — сквозной пайплайн: источник → очередь → итерация → фильтрация
